# SysInfo API

A simple FastAPI application that provides information about
the Linux system on which it is running.

## Endpoints

- `/health`
- `/system/info`
- `/system/cpu`
- `/system/memory`
- `/system/disk`
- `/system/network`
- `/system/processes`

## Technologies

- Python
- FastAPI
- Uvicorn
- psutil
- Linux
- systemd
- Nginx
